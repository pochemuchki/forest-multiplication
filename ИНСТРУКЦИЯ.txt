ОБЩАЯ ТАБЛИЦА ДРУЗЕЙ: настройка (нужен взрослый, около 15 минут)

Что получится: игроки вводят общий «код друзей», и все видят рейтинг друг друга. Он обновляется сам.
Администратор (тот, кто знает секретный код) может убирать лишних игроков и очищать комнату.

Сервер бесплатный: Supabase. Платёжная карта не нужна.

ШАГ 1. Создай аккаунт
  Открой supabase.com, нажми Start your project и войди через GitHub (аккаунт у вас уже есть).

ШАГ 2. Создай проект
  New project -> любое имя (например forest) -> придумай пароль базы (сохрани его) ->
  регион выбери ближайший (например Central EU / Frankfurt) -> Create new project.
  Подожди 1-2 минуты, пока проект создаётся.

ШАГ 3. Включи сервер (один раз)
  1) Открой файл server-setup.sql в Блокноте.
  2) Найди текст ВАШ_СЕКРЕТНЫЙ_КОД_АДМИНА и замени его на свой пароль администратора
     (латинские буквы и цифры, длинный, например Forest-Boss-2026). Запомни его.
  3) В Supabase слева выбери SQL Editor -> New query -> вставь ВЕСЬ текст файла -> нажми Run.
     Должно появиться Success. No rows returned.

ШАГ 4. Скопируй адрес и ключ
  В Supabase: Project Settings -> API (или Data API / API Keys).
  Скопируй Project URL (адрес вида https://xxxx.supabase.co) и ключ anon public (длинный,
  начинается на eyJ...). Если такого нет, подойдёт Publishable key (начинается на sb_publishable_).
  Открой config.js в Блокноте и впиши их между кавычками в url и key. Сохрани.

ШАГ 5. Обнови сайт на GitHub
  Репозиторий -> Add file -> Upload files -> загрузи ВСЕ файлы из этой папки поверх старых
  (index.html, config.js, sw.js, manifest.webmanifest, оба icon-*.png) -> Commit changes.
  Подожди 1-3 минуты. Если на телефоне старая версия, закрой страницу и открой заново.

ШАГ 6. Подключи друзей
  В игре: вкладка «Друзья» -> введи код друзей (придумай любой, например FOREST-7: латиница, цифры,
  дефис, от 3 до 24 знаков) -> Подключиться. Сообщи этот код друзьям, они вводят его так же.
  Рейтинг появится сам, когда каждый сыграет.

ШАГ 7. Администратор
  Вкладка «Друзья» -> «Я администратор» -> введи секретный код из шага 3.
  Появятся крестики ✕ возле игроков и кнопка «Очистить комнату».

ВАЖНО
  * Бесплатный проект Supabase «засыпает», если неделю никто не заходит. Если таблица вдруг
    перестала работать, зайди на supabase.com, открой проект и нажми Resume project.
  * Имена и аватарки хранятся на серверах Supabase за пределами России. Не используйте настоящие
    фамилии и фотографии лица. Лучше смайлики.
  * Если сервер недоступен (например, не открывается без VPN), игра продолжит работать, а друзья
    смогут обмениваться кодами героев на вкладке «Друзья».
  * Секретный код администратора не передавайте детям и друзьям.
