Лесные приключения: таблица умножения — файлы для своего сайта

Что здесь:
  index.html            — сама игра (одним файлом, ничего не скачивает из интернета)
  manifest.webmanifest, sw.js, icon-192.png, icon-512.png — чтобы игру можно было
                          «установить» на телефон и открывать без интернета

Как выложить (нужен взрослый):
  1. Создайте бесплатный сайт-папку: GitHub Pages, Cloudflare Pages, Яндекс Облако
     (Object Storage со статическим сайтом) или любой обычный хостинг.
  2. Загрузите ВСЕ пять файлов в одну папку (index.html должен быть в корне).
  3. Откройте полученную ссылку на телефоне БЕЗ VPN и проверьте, что игра открылась.

Без сайта: можно просто отправить файл index.html другу в мессенджер,
и он откроется в браузере телефона и будет работать без интернета.

Важно: на своём сайте прогресс хранится только в браузере на этом телефоне,
общая таблица друзей работает только внутри Claude.
